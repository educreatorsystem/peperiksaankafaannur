KAFA — VERSI GITHUB PAGES

URL Apps Script cikgu telah dimasukkan ke dalam index.html.
Paparan dan login berjalan di GitHub Pages; data dibaca/disimpan melalui Apps Script dengan semakan akses di pelayan.

1. KEMAS KINI APPS SCRIPT (WAJIB SEKALI)
- Buka projek Apps Script sedia ada.
- Gantikan semua kod Code.gs dengan apps-script/Code.gs dalam pakej ini.
- Kekalkan fail Index HTML lama di projek Apps Script. Fail tersebut diperlukan jika cikgu membuka URL Apps Script secara terus.
- Kekalkan Script Properties sedia ada. Jika setup_ sudah berjaya dijalankan dahulu, TIDAK perlu jalankan semula.
- Jika belum setup: tetapkan GURU_USERNAME dan GURU_PASSWORD (minimum 10 aksara) dalam Script Properties, lalu Run setup_.
- Pilih Deploy > Manage deployments > ikon pensel > Version: New version > Deploy.
- Pastikan Execute as: Me dan Who has access: Anyone (tertakluk dasar akaun).
- Edit deployment sedia ada untuk mengekalkan URL yang cikgu berikan. Jika memilih New deployment dan mendapat URL lain, kemas kini APPS_SCRIPT_URL dalam index.html.

Mengapa perlu kemas kini: kod lama menerima panggilan google.script.run dari halaman Apps Script sahaja. Versi ini menambah endpoint doPost JSON untuk GitHub Pages; tetapan, data dan akaun guru sedia ada dikekalkan.

2. UPLOAD KE GITHUB
- Cipta atau buka repository untuk sistem.
- Pilih Add file > Upload files.
- Upload KANDUNGAN folder github-pages, terutama index.html, ke aras utama repository.
- Commit changes. Jangan upload fail ZIP sahaja; ekstrak dahulu.
- Fail .nojekyll disertakan sebagai pilihan. index.html sahaja mencukupi untuk halaman ini.
- Folder apps-script dan panduan tidak perlu dimuat naik ke repository.

3. AKTIFKAN GITHUB PAGES
Settings > Pages > Build and deployment:
Source: Deploy from a branch
Branch: main
Folder: / (root)
Save.
Tunggu penerbitan selesai dan buka pautan laman yang dipaparkan oleh GitHub.

4. SEMAK SELEPAS PUBLISH
- Login guru.
- Pilih kelas, pentaksiran, subjek. Simpan satu rekod ujian yang sesuai.
- Muat semula laman, login semula, pastikan rekod dibaca semula.
- Login ibu bapa dengan No KP murid tersebut; semak hanya slip murid itu dipaparkan.
- Uji Cetak / Simpan PDF.

STATUS PENGUJIAN
Sintaks JavaScript, dispatch endpoint, penolakan tindakan tidak dibenarkan dan format respons diuji secara tempatan. Ujian fungsi simpan/baca dan sekatan peranan menggunakan simulasi perkhidmatan Google turut lulus.
Sambungan merentas domain dari GitHub ke deployment sebenar belum diuji. Ia memerlukan cikgu memasang endpoint baharu dan menerbitkan GitHub Pages dahulu. Tiada markah sebenar ditulis semasa penyediaan pakej ini.

Jika mesej respons bukan JSON atau sambungan gagal muncul, semak bahawa Code.gs baharu telah dideploy sebagai NEW VERSION dan akses ialah Anyone. Membuka URL /exec terus masih memaparkan antaramuka Apps Script lama; ini normal kerana API GitHub menggunakan POST.
Jangan tukar fetch kepada no-cors: sistem perlu membaca pengesahan simpan daripada pelayan.

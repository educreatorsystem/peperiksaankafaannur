Guru: pilih Guru, masukkan kata laluan Guru123. Tiada nama pengguna diperlukan.
Ibu bapa: pilih Ibu bapa, masukkan No KP murid seperti sebelum ini.
Paparan julat markah dan gred telah dibuang daripada login.
Nama sekolah pada antaramuka: KAFA AN NUR. Pada slip Jawi: کافا النور.

1. APPS SCRIPT
Gantikan Code.gs menggunakan apps-script/Code.gs.
Gantikan kandungan fail HTML Index menggunakan apps-script/Index.html.
Jika setup pernah selesai, tidak perlu jalankan setup_ semula. Tetapan GURU_USERNAME/GURU_PASSWORD/GURU_HASH lama tidak digunakan untuk login versi ini.
Jika ini pemasangan pertama, jalankan setup_ untuk mencipta tab rekod.
Deploy > Manage deployments > Edit > New version > Deploy.
Kekalkan URL deployment sedia ada, Execute as Me, akses Anyone.
Kata laluan disahkan pada pelayan; ia tidak diletakkan dalam fail HTML GitHub.

2. GITHUB
Upload github-pages/index.html ke aras utama repository dan gantikan index.html lama. Commit changes.
Settings > Pages: Deploy from a branch, main, / (root).
Selepas penerbitan selesai, muat semula laman. Jika halaman lama masih muncul, gunakan hard refresh atau buka tetingkap incognito.
Jangan upload ZIP sahaja. Folder apps-script digunakan dalam editor Apps Script; hanya kandungan folder github-pages perlu di GitHub.
